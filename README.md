# Emergent — Assistant Activity Record

A sanitized, dated record of work performed by Emergent Tech Group's AI assistants.

## Purpose
Keep a clear, shareable history of what the assistants worked on, with findings and
limitations, so the team has an auditable trail. This repository contains **no personal
information, no partner-portal data, no customer or production data, and no credentials**.
All entries are generalized on purpose.

## Contents
- `docs/activity-log.md` — dated, high-level log of assistant activity.
- `docs/assessment-log.md` — observations, limitations, and the approvals still needed.
- `media/` — sanitized graphics and summary clips generated from the log.

## Data handling
- Each entry is marked **Proposal**, **Observation**, or **Approved action**.
- No action is described as completed unless it actually was.
- Nothing sensitive (emails, names, tokens, portal or customer data) is committed here.
